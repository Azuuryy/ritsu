# Ritsu — Torii offline foundation

This checkout is the local-only Ritsu foundation, based on Torii v2026.1026.0-torii. Torii names, visuals and skin component identifiers are intentionally retained.

Run the portable package with Launch Ritsu.cmd. Runtime network access, authentication, updates, telemetry, external links and server integrations are disabled. Use the Torii storage setup to link an existing osu!lazer folder, or keep local Ritsu storage. Import local .osz, .osk and .osr files; original archives are preserved.

Build instructions, validation and roadmap: see ../README.md, ../Build.ps1, ../VALIDATION.md and ../ROADMAP.md. The full original Torii README is retained in README.Torii.md.
