# Ritsu release artifacts

Generated by [`Package.ps1`](../Package.ps1). Do not edit the archives by hand.

## Build every platform

From the repository root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Package.ps1
```

The version comes from [`VERSION`](../VERSION) (`0.3.0` for this release). Requirements: Windows x64, the .NET 10 SDK, Python 3, and Internet access for the first package restore. Pass `-SkipBootstrap` when the pinned client, framework and resources are already prepared, `-SkipPublish` to package the existing `.cache\Ritsu-<version>-<rid>` outputs, or `-Platforms win-x64,linux-x64` to restrict the build.

To package only the Windows build:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Package.ps1 -Platforms win-x64
```

## Outputs

| Platform | Archive | Contents |
| --- | --- | --- |
| Windows x64 | `Ritsu-<version>-win-x64.zip` | `torii.exe`, `Launch Ritsu.cmd`, documentation and licences |
| Linux x64 | `Ritsu-<version>-linux-x64.tar.gz` | `torii`, executable `Launch Ritsu.sh`, documentation and licences |
| macOS Intel | `Ritsu-<version>-osx-x64.zip` | `Torii Nova.app` (unsigned), documentation and licences |
| macOS Apple Silicon | `Ritsu-<version>-osx-arm64.zip` | `Torii Nova.app` (unsigned), documentation and licences |

Every archive is accompanied by a `.sha256` sidecar in `sha256sum` format.

## Scope and limitations

- Only the Windows x64 package is launched and validated on the build machine.
- Linux and macOS packages are cross-published from Windows. They are preview builds for volunteer compatibility feedback, not confirmed supported builds, and they are unsigned; macOS shows a Gatekeeper warning.
- Building replaces archives with the same version. Remove old `Ritsu-<old version>-*` files when they are no longer needed.
